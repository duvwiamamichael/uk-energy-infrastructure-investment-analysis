# UK Energy Infrastructure Investment Analysis

## Project Overview

This project assesses seven UK energy infrastructure asset classes to identify where investment may offer the strongest combination of financial performance, risk, technological attractiveness and decarbonisation potential.

The analysis combines quantitative analysis in **Excel** with an interactive **Power BI dashboard**, using 420 project-level observations across:

- Solar PV
- Offshore Wind
- Battery Storage
- Heat Pumps
- Hydrogen
- Gas Infrastructure
- CCUS

## Analytical Approach

The analysis evaluates each asset class across four perspectives:

**Technological Attractiveness → Financial Performance → Risk → Carbon Impact**

Financial performance is assessed using **ROI and NPV**, while technology maturity, risk and estimated carbon savings provide additional investment considerations.

The Excel model also includes **What-If and Scenario Analysis** to explore how changes in assumptions can affect investment outcomes.

## Key Findings

- **Solar PV, Offshore Wind and Battery Storage** demonstrate the strongest overall investment cases.
- **Heat Pumps** show high technological attractiveness but face deployment and workforce constraints.
- **Hydrogen** has significant long-term decarbonisation potential but requires a more selective investment approach.
- **CCUS** currently presents the weakest financial case under the assumptions used.
- The analysis demonstrates why investment decisions should consider **financial return, risk, technology maturity and decarbonisation impact together**.
